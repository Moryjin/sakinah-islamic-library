# سَكينة v1.0.11 — مدير التنزيلات

يضيف هذا الإصدار شاشة **مدير التنزيلات** داخل المكتبة لإدارة حزم المصحف وصحيحي البخاري ومسلم والتلاوات المرخّصة من مكان واحد.

تظهر حالة كل تنزيل وشريط التقدم، ويمكن للمستخدم إلغاء المهمة النشطة أو حذف الملف المكتمل أو إعادة المحاولة بعد الفشل. عند الإلغاء أو الخطأ يُنظّف التطبيق الملف الجزئي بدل تركه في مساحة التخزين. يعيد المدير فحص الملفات المكتملة عند فتحه ويعرض حجمها الحالي.

الإصدار يرفع نسخة التطبيق إلى **1.0.11** ورقم بناء Android إلى **12**. اجتازت الدفعة فحوص Expo Doctor والأنواع والاختبارات والأسلوب ومنع الإعلانات وتصدير Android. يبقى اختبار التنزيل والإلغاء على هاتف فعلي خطوة مطلوبة قبل اعتماد السلوك الميداني النهائي.

# سَكينة 1.0.7

إصدار يركز على القراءة الموثقة والتصفح دون اتصال.

## أبرز الإضافات

- قارئ مصحف متسلسل يضم آيات كل سورة في متن واحد باتجاه RTL، مع تنزيل اختياري للمصحف كاملًا للقراءة دون اتصال.
- قارئا صحيحي البخاري ومسلم بتحميل متدرج، وفهرس نطاقات تفاعلي للأحاديث، وتنزيل اختياري للحزم داخل مساحة التطبيق.
- إعداد قراءة محفوظ لتغيير حجم الخط في المصحف والحديث والأذكار والكتب.
- واجهة أذكار شبكية محسنة، ومركز تغطية للكتب يبيّن القراءة المباشرة أو رابط المصدر وحالة التنزيل لكل باب.
- فصل فهارس المحتوى عن دليل المصادر والتحقق، مع حواجز روابط HTTPS والمصادر المسموحة.

## التحقق

اجتاز المشروع Expo Doctor، وفحص الأنواع، والفحص الأسلوبي، والاختبارات، وتصدير Android. يجب إنتاج APK من النسخة المحفوظة في منصة المشروع عبر زر Publish.

## ملاحظة المصادر

المحتوى الذي تتوفر له بيانات منظمة ومسار استخدام مناسب يعرض أو ينزّل داخل التطبيق. أما الكتب التي لا تتوافر لها رخصة إعادة توزيع واضحة، فيقدّم التطبيق فهرسًا ورابط وصول موثقًا إلى مصدرها بدل تضمين نسخة محلية غير مصرح بها.

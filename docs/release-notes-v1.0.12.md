# سَكينة v1.0.12 — سلامة مدير التنزيلات وتوثيقه

يعالج هذا الإصدار استقرار مدير التنزيلات أثناء التحديث المتكرر لأشرطة التقدم. أصبحت تحديثات حالة React محمية بعد تفكيك المزود، وتُلغى المهام النشطة عند تفكيكه، وتُفرغ مراجع المهام بدل بقائها في الذاكرة. كما تُخنق تحديثات التقدم إلى فاصل زمني قصير مع إظهار البداية والنهاية فورًا، ما يقلل إعادة الرسم من دون إخفاء حالة التحميل.

أضيف README تقني شامل يشرح طبقات التنزيلات، التخزين المحلي، الإلغاء والتنظيف، والتحقق من المصدر، وخطة اختيارية لربط تفضيلات التنزيل بقاعدة بيانات مستقبلًا من دون مزامنة الملفات أو مسارات الجهاز.

يرفع الإصدار النسخة إلى **1.0.12** ورقم بناء Android إلى **13**. اجتازت الدفعة فحوص الأنواع والاختبارات وتصدير Android. لا يتوفر محاكي Android في بيئة العمل، لذلك يظل اختبار الإلغاء على جهاز حقيقي خطوة مطلوبة.

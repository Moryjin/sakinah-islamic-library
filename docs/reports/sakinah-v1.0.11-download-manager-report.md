# تقرير تحسينات سَكينة v1.0.11 — مدير التنزيلات

> تطبيق ليبي من تطوير عبدالعظيم الشريقي

## الملخص

يقدم إصدار **v1.0.11** واجهة موحدة لإدارة تنزيلات سَكينة من مكان واحد. تجمع الشاشة حزم المصحف وصحيحي البخاري ومسلم والتلاوات المرخّصة، وتعرض حالة كل ملف، وحجم الملف المكتمل، وشريط تقدم للتنزيل النشط، مع إتاحة الإلغاء وإعادة المحاولة والحذف.

## التحسينات المنفذة

| الميزة | ما أضيف |
|---|---|
| مدير تنزيلات مستقل | شاشة `/downloads` متاحة من تبويب المكتبة عبر بطاقة «مدير التنزيلات» |
| التقدم | شريط نسبة مئوية للحزم والتلاوات أثناء التنزيل |
| الإلغاء | زر يلغي المهمة النشطة عبر واجهة Expo FileSystem، ثم يحذف الملف الجزئي |
| الحذف | زر حذف للحزم والتلاوات المكتملة مع تحديث الحالة مباشرة |
| إعادة المحاولة | زر إعادة تنزيل بعد الفشل أو الإلغاء |
| حالة الاستعادة | عند فتح التطبيق، يعيد المدير فحص الحزم والملفات الصوتية المحفوظة ويعرض الحجم الصحيح |
| السلامة | تمرير مهمة التنزيل نفسها إلى المدير مع استمرار تحقق HTTP ونوع الملف وحجمه المضاف في v1.0.10 |

## مسار الاستخدام

يفتح المستخدم تبويب **المكتبة** ثم يختار **مدير التنزيلات**. تعرض الشاشة أولًا حزم المحتوى الثلاث في شبكة من عمودين، ثم قائمة التلاوات المرخّصة. يضغط المستخدم «تنزيل» لبدء المهمة، وتتحول البطاقة إلى شريط تقدم وزر «إلغاء التنزيل». بعد اكتمال المهمة يظهر الحجم وزر «حذف الملف». إذا رفض المصدر الطلب أو انقطع الاتصال، يعرض المدير رسالة خطأ وزر «إعادة المحاولة» ولا يحتفظ بالملف الجزئي.

## الملفات المتأثرة

| الملف | التغيير |
|---|---|
| `app/downloads.tsx` | شاشة إدارة التنزيلات وشريط التقدم والإلغاء والحذف |
| `lib/download-manager.tsx` | حالة مركزية للمهام النشطة والملفات المكتملة وعمليات الاستعادة |
| `lib/quran-pack.ts` | تمرير مهمة تنزيل المصحف وتنظيف الملف عند الإلغاء أو الخطأ |
| `lib/hadith-packs.ts` | تمرير مهمة تنزيل الصحيحين وتنظيف الملف عند الإلغاء أو الخطأ |
| `lib/audio-downloads.ts` | تمرير مهمة تنزيل الصوت وتنظيف الملف عند الإلغاء أو الخطأ |
| `app/_layout.tsx` | إضافة مزود مدير التنزيلات ومسار الشاشة |
| `app/(tabs)/library.tsx` | إضافة مدخل ظاهر إلى مدير التنزيلات |
| `app.config.ts` | الإصدار 1.0.11 ورقم بناء Android 12 |

## حدود التحقق

تحققت هذه الدفعة برمجيًا ومن خلال اختبار الوحدات وتصدير Android. لم يُختبر إلغاء تنزيل حي أو التشغيل بلا اتصال على هاتف Android فعلي ضمن جلسة العمل؛ لذلك ينبغي تثبيت بناء v1.0.11 على هاتف وتجربة تنزيل ملف ثم إلغائه ثم حذفه للتأكد النهائي من سلوك منصة الجهاز.

# سَكينة v1.0.15 — تثبيت تنزيل الحزم والتلاوات

يعالج هذا الإصدار أسبابًا محتمَلة لتعطل التنزيل في النسخة المثبتة على الهاتف. قبل بدء أي تنزيل، يحذف التطبيق هدف الحفظ السابق أو الملف الجزئي بعملية آمنة، ثم يعيد إنشاء المهمة. بذلك لا يمنع ملف متبقٍ محاولة جديدة.

أصبحت ملفات التلاوات تستخدم أسماء قصيرة وثابتة مشتقة من الرابط بدل تضمين الرابط المشفّر كاملًا في اسم الملف. يمنع ذلك تجاوز حد طول اسم الملف في Android عند تنزيل روابط وسائط طويلة.

إذا تعذر حفظ سجل التنزيل المحلي، يحذف التطبيق الملف الذي تم تنزيله بدل ترك ملف يتيم يعطل محاولة لاحقة. كما أصبحت رسالة الخطأ تميّز مشكلات مساحة الحفظ والاسم الطويل والمسار عن رفض المصدر أو ضعف الشبكة.

يرفع الإصدار نسخة التطبيق إلى **1.0.15** ورقم بناء Android إلى **16**. اجتازت الدفعة اختبارات المشروع وفحص TypeScript وExpo ESLint وتصدير Android. لم يتوفر هاتف أو محاكي Android لاختبار التنزيل الحي في بيئة العمل.

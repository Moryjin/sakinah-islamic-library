# سَكينة v1.0.10 — إصلاح التنزيلات وشبكة الأذكار

## إصلاح منظومة التنزيل

راجعت هذه الدفعة مسارات تنزيل المصحف والصحيحين والتلاوات. أصبح التطبيق يتحقق من رمز استجابة HTTP ونوع المحتوى وحجم الملف قبل إعلان نجاح التنزيل. لا تُحفظ صفحات الخطأ أو الملفات الصغيرة كملفات صوت، وتُحذف الملفات الجزئية أو الفاشلة تلقائيًا.

تُحفظ التلاوات بالامتداد الصوتي الصحيح بدل امتداد عام، وتظهر رسالة عملية عند حدّ الطلبات أو عند وصول محتوى غير صوتي. عُدّل رابط سعود الشريم إلى نسخة MP3 مرمّزة من الملف نفسه بعد تحقق الاستجابة السليمة، مع بقاء صفحة المصدر والترخيص ذاتيهما.

## واجهة الأذكار والوضع المظلم

تحولت تصنيفات الأذكار إلى شبكة React Native صريحة من عمودين، مع توزيع متساوٍ ومساحة لمس مناسبة على Android. كما استُخدمت ألوان النصوص والحدود عالية التباين في الوضع المظلم لضمان وضوح العنوان والنص الثانوي وحالة الزر.

## التحقق

اجتازت الدفعة فحص Expo Doctor والأنواع والأسلوب والاختبارات، بما فيها اختبار جديد يرفض استجابة 429 وملفات HTML الصغيرة. كما نجح تصدير Android. تحققت الاستجابات المباشرة للمصحف والصحيحين وتلاوات ماهر المعيقلي والسديس والشريم؛ يبقى اختبار التنزيل والتشغيل دون اتصال على هاتف فعلي خطوة مطلوبة قبل الاعتماد النهائي.

# سَكينة

> **لا سند، لا نص**

**سَكينة** تطبيق جوال عربي بواجهة RTL يجمع مسارات قراءة إسلامية منظمة مع منهج شفاف للتوثيق. لا تُعرض مادة دينية داخل التطبيق إلا مع بطاقة مصدر يمكن فتحها ومراجعة موضعها.

## الفكرة والهوية

يمزج سَكينة بين هدوء القراءة ووضوح المرجع. تقوم الهوية البصرية على الأخضر الزمردي والعاجي الدافئ والذهبي المعتّق، فيما تركز التجربة على القراءة بيد واحدة، والوضع المظلم، والانتقالات القصيرة الهادئة.

| العنصر | الوصف |
|---|---|
| الاسم | سَكينة |
| العبارة المنهجية | **لا سند، لا نص** |
| الاتجاه | العربية RTL |
| المنصات | Android وiOS عبر Expo |
| النمط | وضع فاتح ووضع مظلم |

## المبدأ المنهجي

لا يساوي سَكينة بين النص والمعلومة المرسلة. لذلك يفرض التطبيق بطاقة توثيق قبل عرض أو حفظ أي مادة. في الحديث، تشمل البطاقة السند والراوي والمصدر والكتاب والباب والرقم والتخريج ودرجة الحديث وحكم المحدّث. وفي القرآن والتفسير والكتب، تشمل السورة والآية أو اسم الكتاب والمؤلف والطبعة والموضع والرابط.

> لا يستخدم التطبيق الفهارس أو الاقتباسات بوصفها فتوى شخصية أو جوابًا للنوازل الفردية. باب الفتاوى إحالي إلى المراجع المعتمدة، ولا يغني عن سؤال أهل العلم.

## الأبواب المتاحة

| الباب | ما يعرضه |
|---|---|
| القرآن الكريم | نص الآيات مع السورة والآية والرابط المرجعي |
| القراءات العشر | القارئ والرواية والطريق والموضع عند إدراج كل وجه |
| التفسير | إحالات منفصلة لتفاسير السعدي وابن كثير والبغوي والطبري والقرطبي |
| صحيح البخاري وصحيح مسلم | المتن والسند والتخريج والدرجة داخل بطاقة التوثيق |
| الأذكار والأدعية | تصنيف بحسب الوقت والمناسبة مع تذكيرات محلية اختيارية |
| الورد اليومي | ورد قرآني موثق ومتابعة محلية |
| التراث والعلماء | البداية والنهاية، ابن تيمية، النووي، ابن باز، وكتاب التوحيد |
| المذاهب الأربعة | مداخل موثقة للحنفي والمالكي والشافعي والحنبلي مع نسبة دقيقة للكتب |
| الفتاوى | إحالات موثقة إلى فتاوى ابن باز ومجموع فتاوى ابن تيمية |

## قائمة المصادر المسموحة

المصادر الآتية هي قائمة البداية المعتمدة داخل المشروع. لا يُضاف مصدر جديد أو مادة جديدة قبل مراجعة الرابط والموضع وبيانات الاستشهاد.

| المصدر | الاستخدام |
|---|---|
| [مجمع الملك فهد لطباعة المصحف الشريف](https://qurancomplex.gov.sa/) | نص القرآن وإصدارات المصاحف والروايات |
| [مشروع المصحف الإلكتروني بجامعة الملك سعود](https://quran.ksu.edu.sa/) | مواضع التفسير وربط السورة والآية |
| [الموسوعة الحديثية في الدرر السنية](https://dorar.net/hadith) | التحقق والتخريج وبيانات الحديث |
| [حصن المسلم](https://hisnmuslim.com/i/ar/1) | فهرسة أبواب الأذكار والأدعية |
| [المكتبة الشاملة](https://shamela.ws/) | الفهارس التراثية وبيانات الطبعات والمواضع |
| [الموقع الرسمي للشيخ ابن باز](https://binbaz.org.sa/) | المؤلفات والفتاوى المنشورة رسميًا |

## التذكيرات المحلية

التذكيرات اختيارية وتعمل محليًا على جهاز المستخدم بعد منح الإذن. تشمل أذكار الصباح والمساء، والصلاة على النبي ﷺ، والورد اليومي. يختار المستخدم التفعيل والساعة المناسبة، ولا يدعي التطبيق أن وقت التذكير وقت شرعي ملزم.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

## المساهمة

نرحب بالمساهمات التي تحسن تجربة القراءة أو التوثيق أو الوصول. قبل فتح طلب دمج لمادة علمية أو دينية، يجب إرفاق المصدر والرابط والموضع، وإضافة بيانات التخريج والدرجة والسند إن كانت المادة حديثًا. راجع [دليل المساهمة](CONTRIBUTING.md) و[منهج المصادر](docs/methodology.md).
